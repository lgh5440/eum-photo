# 이음 포토 교사용 테스트 시나리오

작성일: 2026-05-08

## 목적

교회학교 교사가 행사 사진을 빠르게 확인하고, 학생/인물/공개 여부 기준으로 정리본을 만들 수 있는지 확인한다.

## 준비물

- 행사 사진 20장 이상
- 단체 사진 3장 이상
- 흐린 사진 또는 중복 사진 일부
- 학생 명단 CSV: `docs/sample-roster.csv` 참고 (공개동의 컬럼 포함)

## 첫 화면 점검

1. 처음 들어왔을 때 **4단계 가이드 카드**(사진 추가 → 행사명 → 학생 명단 → 내보내기)가 보이는지.
2. 빨간 박스로 「새로고침하면 사진 사라짐 — 작업 저장으로 백업」 안내가 보이는지.

## 본 시나리오

1. **사진 추가** — 「사진 선택」 또는 빈 화면에 드래그 앤 드롭. 사진이 들어온 후에도 화면 어디든 추가 드래그로 더 넣을 수 있다.
2. **행사명 입력** — 사이드바 「정리 기준 → 행사명」에 「봄 수련회」처럼 입력. 비워두면 「주일학교」로 저장된다는 빨간 안내가 뜬다.
3. **학생 명단 CSV** — 「학생 명단 CSV」 버튼으로 `sample-roster.csv` 불러오기.
   - 명단 칩 색이 매칭(녹) / 미매칭(회) / 명단 외(빨강)로 구분되는지.
   - `공개동의` 컬럼이 인식되어 ✓ / ✗ / ? 표식이 칩에 붙는지.
4. **태그 적용** — 사진 몇 장을 선택한 뒤 명단 칩(예: 김하은)을 누르거나 「학생 이름 직접 입력」 → 「선택 N장에 적용」.
5. **단체 사진 확대** — 사진 카드 「확대」 버튼으로 뷰어 진입. 헤더에 「ESC ← → 1234」 안내 칩이 보이는지.
6. **얼굴 있는 사진 찾기** — 사이드바 「인물 사진 찾기 → 얼굴 있는 사진 찾기」 실행. 얼굴 박스가 확대 보기에 표시되는지.
7. **인물 폴더 만들기** — 확대 보기에서 얼굴 박스 클릭 → 사이드바 「인물 폴더 → 인물 이름」 입력 후 등록.
8. **인물 후보 찾기** — 인물 폴더에서 「후보 찾기」를 눌러 유사도 점수가 표시된 후보가 나오는지. 승인/제외 동작 확인.
9. **단축키 분류** — 사진을 클릭해 활성화한 뒤 키보드 1·2·3·4로 보관·대표·공개후보·제외 상태를 빠르게 변경. 사진 카드에 단축키 배지가 보인다.
10. **공개 미동의 검출** — 「박시온」(미동의) 학생이 태그된 사진을 「공개후보」로 두면 사진 카드에 빨간 「공개 미동의: 박시온」 뱃지가 뜨고 정리안 패널 「검토 필요」에 자동 표시되는지.
11. **검토 필요** — 「검토 필요」 항목을 누르면 해당 사진이 확대 보기로 열리는지(「확대해서 확인 →」 라벨 hover).
12. **검색/상태/얼굴 필터** — 사진 목록 상단 필터바에서 검색·상태·얼굴 필터 적용. 「보이는 사진 선택」으로 일괄 선택.
13. **작업 저장** — 상단 「작업 저장」으로 JSON 백업. 새로고침 시 OS 경고 다이얼로그가 뜨는지(beforeunload).
14. **작업 불러오기** — 화면 비운 뒤 원본 사진을 다시 추가하고 「작업 불러오기」로 JSON 선택. 태그·상태·인물 폴더가 복원되는지.
15. **누적 통계** — 「이 행사 누적에 추가」를 누른 뒤 상단 학생별 누적 사진 수가 표시되는지. 다른 행사 사진으로 다시 추가하면 학생별 누적이 합산되는지.
16. **로컬 폴더 저장** (Chrome/Edge) — 상단 「로컬 폴더 저장」 → 폴더 선택. 행사/상태/인물 하위 폴더와 `_정리안.csv` / `_정리안.json`이 생기는지.
17. **정리본 ZIP** — 다른 브라우저에서 「정리본 ZIP」으로 같은 폴더 구조를 ZIP으로 받기.
18. **정리표 ▾** — 사진 없이 정리표만 받고 싶을 때 「정리표 ▾」 → CSV/JSON.
19. **위험 동작 보호** — 「비우기」 / 「기록 비우기」 클릭 시 확인 다이얼로그가 뜨는지.

## 모바일 점검

- 화면 좌상단 ☰ 버튼으로 사이드바를 열고 닫을 수 있는지.
- 사이드바 백드롭을 누르면 자동으로 닫히는지.
- 사진 카드와 필터바가 1열로 보기 좋게 정렬되는지.

## 통과 기준

- 사진 원본이 서버로 올라가지 않는다는 안내가 명확하다 (사이드바 「로컬 원칙」 + 빈 화면 안내).
- 확대 보기에서 단체 사진 얼굴 확인이 가능하다.
- 학생 태그와 인물 폴더 배정이 교사가 이해할 수 있을 만큼 단순하다.
- 최종 저장 결과에 `_정리안.csv` 와 `_정리안.json` 둘 다 포함된다.
- 공개 후보 사진 중 미동의 학생 포함 같은 위험 항목이 검토 필요로 표시된다.
- 새로고침이나 「비우기」를 실수로 눌러도 작업이 한 번에 사라지지 않는다.

## 기록할 피드백

- 교사가 막힌 단계
- 버튼 이름이 헷갈린 곳
- 자동 후보가 맞았는지 틀렸는지
- 폴더 구조가 실제 업무에 맞는지
- 모바일에서 충분히 사용할 수 있는지
- 단축키와 드래그 앤 드롭을 사용하게 되었는지
