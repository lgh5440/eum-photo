# 이음 포토 교사용 테스트 시나리오

작성일: 2026-05-08

## 목적

교회학교 교사가 행사 사진을 빠르게 확인하고, 학생/인물/공개 여부 기준으로 정리본을 만들 수 있는지 확인한다.

## 준비물

- 행사 사진 20장 이상
- 단체 사진 3장 이상
- 흐린 사진 또는 중복 사진 일부
- 학생 명단 CSV: `docs/sample-roster.csv` 참고

## 테스트 순서

1. `사진 추가`로 행사 사진을 넣는다.
2. `학생 명단 CSV`로 명단을 불러온다.
3. 사진 몇 장을 선택하고 학생 이름 버튼을 눌러 태그가 붙는지 확인한다.
4. 단체 사진을 `확대`해서 얼굴이 확인 가능한지 본다.
5. `얼굴 있는 사진 찾기`를 실행하고, 확대 보기에서 얼굴 박스가 보이는지 확인한다.
6. 얼굴 박스를 선택하고 이름을 입력해 인물 폴더를 만든다.
7. 인물 폴더에서 `후보 찾기`를 눌러 유사도 점수가 붙은 후보가 나오는지 확인한다.
8. 후보 사진을 승인하거나 제외한다.
9. 검색/상태/얼굴 필터로 사진 목록이 잘 줄어드는지 확인한다.
10. `검토 필요` 항목을 눌러 확대 확인으로 이동하는지 본다.
11. `작업 저장`으로 JSON을 저장한다.
12. 화면을 비우고 원본 사진을 다시 추가한 뒤 `작업 불러오기`로 상태가 복원되는지 확인한다.
13. Chrome/Edge에서는 `로컬 폴더 저장`을 실행한다.
14. 지원하지 않는 브라우저에서는 `정리본 ZIP`을 내려받아 폴더 구조를 확인한다.

## 통과 기준

- 사진 원본이 서버로 올라가지 않는다는 안내가 명확하다.
- 확대 보기에서 단체 사진 얼굴 확인이 가능하다.
- 학생 태그와 인물 폴더 배정이 교사가 이해할 수 있을 만큼 단순하다.
- 최종 저장 결과에 `_정리안.csv`가 포함된다.
- 공개 후보 사진 중 이름 미지정 같은 위험 항목이 검토 필요로 표시된다.

## 기록할 피드백

- 교사가 막힌 단계
- 버튼 이름이 헷갈린 곳
- 자동 후보가 맞았는지 틀렸는지
- 폴더 구조가 실제 업무에 맞는지
- 모바일에서 충분히 사용할 수 있는지
