주요 기능

인물별 폴더 분류

사진을 인물 폴더로 드래그만 하면 정리 끝. 원본은 항상 보존됩니다.

다중 선택

Ctrl·Shift·드래그 박스로 여러 장을 한 번에 선택·분류.

라이트박스

사진을 크게 보고 ←/→ 로 넘기며, 그 자리에서 바로 분류.
