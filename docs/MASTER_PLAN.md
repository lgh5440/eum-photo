## 4. 무엇을 안 하는가 (포기 명시)

- Windows 파일 탐색기 자체 임베드 (OS·Electron 한계)
- fs.watch 양방향 라이브 동기 (race·rename 추적 비용 큼)
- Google Drive 자동 동기 (라운드 후반)
- iOS/Android 모바일 (PWA 1단계로 충분)
- alias 사진 모델 (디스크 직접 복사로 대체)

- 일반 사진 보정·편집 (정리 도구지 편집 도구 X)

## 7. 진행 원칙 (벗어나면 미궁)

1. **한 단계 끝나야 다음 단계.** 건너뛰기 X.
2. **검증 기준 100% 통과해야 OK.** 부분 통과는 NOT OK.
3. **막히면 그 자리서 멈춤.** 다른 단계로 도망 X. 진단 → 사용자 보고 → 결정.
4. **일정은 추정.** ±30% 오차 허용. 빗나가면 즉시 사용자 알림.
5. **시간·범위 결정 = 사용자 권한.** 일정 단축·중단·우선순위 변경 자유.
6. **새로 발견한 기능 욕심 X.** 이 문서에 없으면 안 한다. 추가하려면 이 문서부터 갱신.
